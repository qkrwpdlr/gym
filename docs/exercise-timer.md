# 집중 모드 운동 타이머

`30초`, `10초`, `1분 30초`처럼 시간으로 적힌 세트는 집중 모드에서 카운트다운을 보여 준다. 횟수나 `3초 내리기` 같은 템포 설명은 운동 시간으로 읽지 않는다.

- 운동에 진입하거나 휴식이 끝나면 준비 상태로 기다린다. `타이머 시작`을 눌러야 시간을 센다.
- 일시정지·이어서 시작·처음부터를 지원한다. 0초에는 소리와 지원 기기의 진동으로 알리고, 사용자가 `완료`를 누르면 세트를 기록하고 휴식으로 넘어간다.
- `10–20분`처럼 범위가 있으면 최소·중간·최대 목표 시간을 고를 수 있다. 시작 전과 일시정지 상태에서 바꿀 수 있다.
- 시범 시트, 집중 모드 접기, 탭 이동 중에도 진행한다. 미니 바에도 남은 시간을 표시한다. 새로고침 후 진행 중이던 종료 시각 또는 일시정지 상태를 복구한다.
- 시간은 종료 시각과 현재 시각의 차이로 계산한다. 브라우저가 백그라운드에서 실행을 멈췄더라도 다시 열면 경과 시간을 반영한다.

`web/src/exerciseTimer.ts`가 시간 표기와 남은 시간 계산을, `useExerciseTimer.ts`가 수동 시작과 상태 유지를 담당한다. 세트 위치·목표가 바뀌면 새 타이머로 준비한다. 세션 저장은 기존 `gym-v4-timer`를 사용한다.

## 검증 (2026-11-14)

- `cd web && npm run test:timer && npm run lint && npm run build:pages` 통과.
- Playwright Chromium으로 수동 시작, 시작 직후 정지, 일시정지·재개, 초기화, 진행/정지 상태의 새로고침 복구, 시범·접기 중 경과, 0초 후 수동 완료, 휴식 후 다음 세트의 시작 대기, 10초 운동, 걷기 목표 선택을 확인했다.
- 320×568, 375×629, 390×844에서 3종류 시간 운동의 버튼과 화면 배치를 확인했다.
- 기존 19개 루틴 화면, (?) 버튼 142개, 시트 44개, 휴식 타이머, 시범 오프라인 재열기 회귀 검사도 통과했다. 실제 iPhone Safari는 미검증이다.
